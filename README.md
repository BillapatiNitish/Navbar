# Responsive Navbar

A simple and clean navigation bar created using **HTML** and **CSS**. This project is a beginner-friendly practice project to understand how navigation bars are designed and styled.

## Features

* Clean and modern design
* Built with only HTML and CSS
* Flexbox layout for easy alignment
* Navigation links:

  * Home
  * About Us
  * Contact
  * Login
* Simple landing page heading below the navbar
* Easy to customize and extend

## Technologies Used

* HTML5
* CSS3

## Project Structure

```text
Navbar/
│── index.html
│── style.css
└── README.md
```

## What I Learned

While building this project, I learned:

* Creating the structure of a navigation bar using HTML
* Styling elements with CSS
* Using Flexbox for layout and alignment
* Adding colors, spacing, and shadows
* Organizing a simple webpage
